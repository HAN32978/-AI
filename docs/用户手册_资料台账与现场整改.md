# 用户手册：资料台账与现场整改

适用版本：1.1.0；更新：2026-10-08。

## 1. 上传与台账

1. 打开资料库管理，选择当前项目，必要时展开新建项目。
2. 选择文件，填写分类、业务日期、文档编号和版本。
3. DWG/RVT 等导出 PDF/DXF/IFC 后，上传导出件时选择对应原件，保存关联。
4. 提交后切换“文档台账与任务”，点击刷新，查看状态、记录数、索引数和说明。

| 状态 | 含义 |
|---|---|
| 排队中/解析中/索引中 | 正在后台处理，尚未完成 |
| 可检索 | 已完成索引，可用语义问答；Excel 同时有完整记录 |
| 部分解析 | DXF 有范围限制，或 Excel 原表已解析但索引失败；查看说明与索引数 |
| 仅原件归档 | 原件可下载，但内容不能参与语义问答 |
| 处理失败 | 查看错误，修复依赖/文件后重新解析 |

相同文件、相同登记信息不会重复入库。相同项目同文件名不同内容/版本标签会新增版本，默认查询最新成功版本。上传失败的新版本不替换已有可用版本。请保持版本文件名一致；系统尚不自动把不同文件名认定为同一业务文件。

单文件上限 50MB。扫描 PDF 暂无 OCR；DWG/RVT/IFC 本期只归档，RVT 导出 IFC 后仍只归档 IFC，导出文字 PDF 才可查询文字。旧 DOC 建议另存 DOCX/PDF。

## 2. 查全部检查记录

进入完整记录查询，选择项目及文档，输入“9月9日”或完整日期，按原表状态或关键词筛选。页面显示全部匹配总数与当前页，工作表和行号可定位原文。展开原表字段可看到没有映射到标准列的其他原始单元格。

“生成完整筛选清单 CSV”会导出所有匹配行，包含原表字段 JSON；不只导出当前页。没有年份时不补年份，可能同时匹配多年度的同月日资料，应再限定文档。状态空白、待补充或照片占位不等于已整改/未整改。

智能问答输入“查询9月9日全部检查问题”时可自动进入完整记录查询；默认一页 50 条，回答会显示总数和本页条数。更大清单在完整记录页面分页或导出。仅语义问答使用检索 top-k，不据此声称列出所有记录。

## 3. 现场整改资料闭环

1. 在记录查询中选择来源行，登记问题、登记人和责任方；也可在现场整改页面直接登记现场问题。
2. 到资料库上传整改回复、现场照片等依据，确认状态为可检索、部分解析或仅归档。
3. 回到现场整改，选择“登记整改回复”，填写操作人、说明、关联依据并人工确认。
4. 选择“申请人工复查”，填写说明，进入待复查状态。
5. 复查人核实现场与依据后选择“复查通过并销项”或“复查不通过，退回整改”。销项必须关联至少一份本项目已归档依据。
6. 已销项事项出现新情况可重新打开；所有步骤保存为历史事件，可导出 MD 事项记录。

提交照片、LLM 回答、填写“已完成”均不会自动销项。页面仅管理资料闭环，不替代建设、施工、监理、设计单位的现场确认、正式签章与图纸会审程序。

当前单用户演示中操作人是人工填写的姓名，没有账号身份验证。事件时间保存为 UTC；界面时间字符串含 `+00:00`，不能误认为本地时区。对话历史存在内存中，API 重启后不保留；文档、完整记录和整改事件存在 SQLite 中，重启后保留。

## 4. 问答模型与故障

模型配置文件是 `rag_app/config/.env`。云端配置保存在后端，不在前端输入框、源码 MD 或 ZIP 中。修改配置后重启 API。

完整记录查询无需 LLM；语义问答需要可用的问答模型和已索引资料。台账显示索引失败时，可以先查完整 Excel 记录，修复 Embedding 环境后重试。

如果显示无法连接 API，请确认终端当前目录含 `run_api.py`。项目外层目录直接执行 `python run_api.py` 会找不到文件。

## 5. 历史模块

独立图纸审查入口已从主导航移除，代码在 `rag_app/experiments/drawing_review` 保存；主 API 不开放旧审查接口。按该目录 README 显式启动可复现旧实验。
