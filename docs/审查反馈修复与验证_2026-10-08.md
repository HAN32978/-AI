# 审查反馈修复与验证

版本：1.1.1；日期：2026-10-08。依据实际源码、上一版隔离复现和本轮回归结果；不把外部报告文字当作已执行的测试。

## 1. 复现与结论

从 Git 提取上一版提交 `51f55af42cba3fe345eb887a546689029b414004` 的台账和解析源码，以真实 SQLite/Excel、替身向量写入重新运行，确认四项边界缺陷：

| 边界 | 上一版实际结果 | 修复后结果 |
|---|---|---|
| 同项目、同名不同日文件 | 查9日0条、10日1条 | 两份独立保存，两日各1条；只有显式替换才归组 |
| 9种不规整日期 | 保存9行，9日只匹配2行，未暴露未知日期数量 | 匹配7行，另2行日期待核对，原始9行保留 |
| 1条问题与1条合计 | 入库2条问题记录 | 1条问题，合计保留到解析报告 |
| 粘贴照片处带标点 | 被保存为有效原表状态 | 规范状态为空，原字段继续保留 |

`2026年9月` 不含日，无法推断成9月9日；这是必须显式暴露的待核对数据，不应强行转换。跨年份月日匹配是明确功能，本版显示各年度与未登记年份的数量。

## 2. 对审查条目的处理

| 条目 | 实际处理及限制 |
|---|---|
| 1 版本顶替 | 改为独立文档默认，上传时用 replace_document_id 显式替换；旧版不明分组保守恢复独立，原件与旧记录不删除 |
| 2 日期漏查 | 新增纯日期模块；分隔符、中文数字、完整日期时间可识别，缺日/未识别/缺失计数并可查原行；冲突日期列不静默选一个 |
| 3 合计行 | 明确汇总行排除并写入解析报告；带真实问题内容的模糊汇总行保留，不以关键词误删 |
| 4 占位状态 | 清理括号/标点与包含占位标记的状态；带明确整改状态的照片补充说明保留原状态 |
| 5 跨年 | 保持月日跨年查询，但明确展示年份分布；完整日期查询只匹配对应年份 |
| 6 Key错误 | 删除懒依赖构造器的无效捕获；真正初始化/调用处把配置错误转换为服务异常，真实 HTTP 返回503；输入校验仍422 |
| 7 空检索生成 | 无可检索文档或召回为空时，程序直接拒答并跳过模型初始化/调用；有历史对话的空召回也不调用模型改写。非空片段不等于内容适用，未声称消除全部幻觉 |
| 8 FAISS过滤 | 普通搜索、带分数搜索与 LangChain 检索器均转换元数据谓词，适配本机旧包；过滤候选范围覆盖完整索引，代价是大库检索成本，尚未做规模测试 |
| 9 页码 | 历史实验页码统一转换为1起始，加入断言；实验仍不进入主导航 |
| 10 销项依据 | 回复需整改回复类文件，销项需复查依据类文件；原问题表/同哈希副本不能充当完成依据；登记业务日期，校验检查→回复→复查先后及依据日期一致性；文件内容真实性/相关性仍由人核实，归档时间不能当业务发生时间 |
| 11 DXF头 | ASCII 要求实际0/SECTION/2/节名行结构，二进制校验头标记；hello SECTION 0拒绝。仍不是完整DWG/BIM结构验证 |

Excel 读取路径不再无条件导入 DocumentLoader。自动测试仍需安装项目依赖；课程手动演示迁出 tests，文件名多点问题一并消除，不用跳过失败来宣称通过。

## 3. 测试证据与复现条件

- **34项自动回归通过**：12项基础台账、5项原问答、15项新增边界与真实 FAISS、2项历史实验。模型与网络不用于这些业务约束测试，向量替身的用例与真实 FAISS 用例分别说明。
- **66项真实集成检查通过**：不规整及规范合成Excel、HTTP、真实BGE/Chroma、本地Ollama、有来源回答、无资料拒答、空Key503、原件归档、人工流程、服务重启、6页Streamlit AppTest。
- 服务日志另存TXT，JSON记录对应SHA256。合成检查数据不含用户工程资料；本轮云提供商测试在无Key时即被拦截，没有外部模型调用。
